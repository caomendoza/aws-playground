# aws-cao-playground

A minimal Java 21 application using Spring Boot 3.5.16 and Spring Web.
It runs an embedded web server on port 8080. No database, authentication,
Docker, AWS credentials, cloud resources, or external services are needed.
Maven downloads Spring Boot and its dependencies on the first build.

## Prerequisites

- JDK 21
- Apache Maven 3.6.3 or newer, available as `mvn` in PowerShell

Open PowerShell in this project's root directory (the folder containing `pom.xml`).
Check that both Java and Maven use JDK 21:

```powershell
java -version
mvn -version
```

If necessary, select your installed JDK for the current PowerShell session.
Replace the example path with the actual JDK 21 installation directory:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21'
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
java -version
mvn -version
```

## Build and run locally

Build the executable JAR and run the controller test:

```powershell
mvn clean package
java -jar .\target\aws-cao-playground-0.0.1-SNAPSHOT.jar
```

In a second PowerShell window, call the endpoint:

```powershell
(Invoke-WebRequest -Uri 'http://localhost:8080/hello' -UseBasicParsing).Content
```

Expected response (HTTP 200, JSON):

```json
{"message":"Hello from AWS EC2!"}
```

Press `Ctrl+C` in the server's window to stop it.

Alternatively, run directly with Maven:

```powershell
mvn spring-boot:run
```

Run only the tests:

```powershell
mvn test
```

If port 8080 is already in use, choose another port and use it in the URL:

```powershell
java -jar .\target\aws-cao-playground-0.0.1-SNAPSHOT.jar --server.port=8081
```

## Project structure

```text
pom.xml
src/
  main/java/com/example/awstraining/
    AwsTrainingApplication.java
    controller/Controller.java
  test/java/com/example/awstraining/
    ControllerTest.java
target/                              # Generated by Maven
  aws-cao-playground-0.0.1-SNAPSHOT.jar
```

- `pom.xml` sets Java 21, declares Spring Web and test dependencies, and configures executable JAR packaging.
- `AwsTrainingApplication.java` is the entry point. It starts Spring Boot and the embedded server.
- `controller/Controller.java` handles `GET /hello`. Spring converts the returned Java map into JSON automatically.
- `ControllerTest.java` uses `@WebMvcTest` and MockMvc to check HTTP 200, the JSON content type, and the exact response object without opening a network port.
- `target/` holds build output. The executable JAR includes the application, dependencies, and server; run it wherever Java 21 is installed.

The base package is `com.example.awstraining`. Keeping the controller inside this
package lets Spring Boot discover it automatically. No application configuration
file is needed for these defaults.

## Run on your server

Copy the built JAR to your server with Java 21 installed. From the directory
containing the JAR, run:

```bash
java -jar aws-cao-playground-0.0.1-SNAPSHOT.jar
```

The application listens on port 8080. This command runs it in the foreground;
press Ctrl+C to stop it. Maven is only needed to build the JAR.
